FOODIEHUB — FRONTEND WEBSITE

Files included:
- index.html   Home page
- menu.html    Menu with food categories
- offers.html  Offers and promo cards
- about.html   Brand story and values
- contact.html Contact form and FAQ
- cart.html    Static cart / checkout preview
- style.css    Shared responsive styling for all pages

HOW TO RUN IN VS CODE
1. Extract the FoodieHub.zip file.
2. Open the FoodieHub folder in Visual Studio Code.
3. Install the Live Server extension if you do not have it.
4. Right-click index.html and select “Open with Live Server”.
5. Use the top navigation to visit each page.

VIDEO BACKGROUNDS
The hero and selected feature sections use a remote Pexels video with a poster image fallback. The video needs an internet connection. The browser may pause autoplay if data-saving or autoplay settings prevent it.

IMPORTANT
This is a static HTML + CSS project. The cart, quantity controls, promo code, contact form and newsletter are design demonstrations only. They do not store orders, send messages or take payments. JavaScript and a backend would be needed to make them functional.

IMAGES AND FONTS
Food photography is loaded from Unsplash and fonts from Google Fonts, so those visual assets need an internet connection.
